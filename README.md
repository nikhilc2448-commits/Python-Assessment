# Python Assessment – Pandas Behaviour & Debugging

This repository contains my Python assessment completed as part of the Data Analyst Training.

The assessment focuses on understanding pandas behaviour, debugging common issues, and writing defensive code.

## Topics Covered

- Views vs copies in pandas
- Chained assignment and Copy-on-Write
- `inplace=True` behaviour
- Merge cardinality and duplicate keys
- `validate` parameter in `pd.merge()`
- `groupby()` with missing values
- NaN comparison using `==` and `.equals()`
- Handling division by zero
- Basic DataFrame validation and debugging checks

## Assessment

The assessment contains answers for:

- Q1–Q5: Predict the Output
- Q6–Q8: Write the Code
- Q9–Q10: Debugging
